# 🔐 File Hash Checker

## About
File Hash Checker is a beginner cybersecurity project built using Python in Google Colab. It calculates SHA-256 hashes of files and compares hashes to check file integrity.

## Features
- Generate SHA-256 hashes for files.
- Compare hashes to check if they match.
- Display the comparison result.

## Tools Used
- Python
- Google Colab
- SHA-256 Hashing

## What I Learned
- Basics of cryptographic hashing.
- How to generate file hashes using Python.
- How hash comparison helps verify file integrity.

## Project Status
Completed as a beginner project while learning cybersecurity and Python.
